# Arquivos iniciais — Capítulo 11

Extraia ou copie a pasta completa antes de começar e abra o terminal nela. Os dois arquivos JSON representam casos de teste diferentes.

Execute `python verificar_capitulo.py` antes das atividades. A mensagem `Ambiente pronto para o Capítulo 11.` confirma apenas que o Python está executando na pasta correta.

| Arquivo | Finalidade |
|---|---|
| `produtos_validos.json` e `produtos_corrompidos.json` | Caminhos de teste. |
| `catalogo_base.py` | Prática acompanhada. |
| `captura_ampla.py` | Oficina sobre `except:`. |
| `verificar_capitulo.py` | Verificação inicial do terminal. |

Não corrija `produtos_corrompidos.json`: a vírgula extra é intencional. Se quiser repetir os testes, preserve uma cópia limpa dos arquivos iniciais.
