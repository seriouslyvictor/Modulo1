# Imagens do capítulo

Use esta pasta somente quando uma imagem tornar uma ação ou relação mais fácil de compreender do que uma instrução textual.

## Convenções

- Nomes de arquivo usam prefixo numérico, caracteres ASCII e `snake_case`.
- Exemplo: `01_selecionar_interpretador.png`.
- Capturas de tela mostram apenas a área relevante.
- Informações pessoais, caminhos de usuário, contas e notificações devem ser ocultados.
- Anotações usam setas, contornos e números com moderação.
- Toda imagem deve possuir texto alternativo significativo no Markdown.
- Toda ação mostrada visualmente também deve ser descrita em texto.
- Capturas de interfaces devem ser verificadas antes da publicação final.
