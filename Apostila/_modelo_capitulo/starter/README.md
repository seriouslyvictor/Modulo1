## Como começar

1. Copie esta pasta para um local em que você possa editar os arquivos.
2. Abra a pasta copiada no VS Code.
3. Selecione o interpretador indicado no capítulo.
4. Execute `[arquivo_inicial.py]`.
5. Compare o resultado com a saída inicial mostrada em `capitulo.md`.

## Regras para autoria do capítulo

<!-- Remova esta seção no pacote entregue ao estudante. -->

- O código inicial deve executar ou falhar apenas da maneira intencional descrita.
- Não inclua partes essenciais da solução por conveniência.
- Inclua dados suficientes para testar casos comuns e limites.
- Use somente conceitos já ensinados ou explicados no próprio capítulo.
- Não inclua dados pessoais, senhas, tokens ou informações institucionais.
- Teste a pasta a partir de uma cópia limpa antes de publicar.
