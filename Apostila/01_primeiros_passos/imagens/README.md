# Capturas planejadas — Capítulo 1

As capturas devem ser produzidas no ambiente Windows usado para validar a edição final. Não devem conter nome de usuário, conta institucional, notificações ou caminhos pessoais.

| Arquivo | Conteúdo | Anotação necessária |
|---|---|---|
| `01_extensao_python.png` | Extensão Python publicada pela Microsoft | Destacar nome, publicador e botão de instalação/estado. |
| `02_selecionar_interpretador.png` | Paleta `Python: Select Interpreter` | Destacar comando e instalação de Python 3 escolhida. |
| `03_run_python_file.png` | Arquivo aberto no VS Code | Destacar botão **Run Python File** e terminal com saída. |
| `04_python_install_manager.png` | Instalação oficial de Python no Windows | Destacar origem oficial e ação principal. |

Toda captura deverá possuir uma instrução textual equivalente em `capitulo.md`. A imagem auxilia a localização visual, mas não será o único meio de compreender a etapa.
