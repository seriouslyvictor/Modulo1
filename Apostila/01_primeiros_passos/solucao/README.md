# Soluções comentadas — Capítulo 1

Consulte esta pasta somente depois de tentar as atividades e participar da correção.

| Arquivo | Finalidade |
|---|---|
| `mensagem_corrigida.py` | Correção da oficina de depuração. |
| `apresentacao_loja.py` | Uma solução possível para o exercício independente. |
| `status_ambiente.py` | Uma solução possível para a tarefa de saída. |

## Estratégia utilizada

As soluções usam somente comentários e `print()`, pois variáveis e entrada de dados pertencem ao próximo capítulo. Cada mensagem aparece em uma chamada separada para tornar a execução sequencial visível.

## Como executar

Abra o terminal dentro desta pasta e informe o arquivo desejado:

```powershell
python apresentacao_loja.py
```

Se o ambiente do laboratório utiliza o iniciador `py`, substitua `python` por `py`.
