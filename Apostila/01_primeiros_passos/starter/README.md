# Arquivos iniciais — Capítulo 1

Esta pasta contém os arquivos necessários para verificar o ambiente e praticar depuração.

| Arquivo | Finalidade |
|---|---|
| `verificar_ambiente.py` | Confirmar que o interpretador executa um arquivo Python. |
| `mensagem_com_erro.py` | Investigar e corrigir um erro de sintaxe intencional. |

## Como começar

1. Crie sua pasta `01_primeiros_passos` dentro de `curso_python`.
2. Copie os dois arquivos para essa pasta.
3. Abra a pasta completa no VS Code.
4. Execute primeiro `verificar_ambiente.py`.
5. Não altere `mensagem_com_erro.py` antes da oficina de depuração.

Saída inicial esperada de `verificar_ambiente.py`:

```text
Python conseguiu executar este arquivo.
O ambiente está pronto para a primeira aula.
```
