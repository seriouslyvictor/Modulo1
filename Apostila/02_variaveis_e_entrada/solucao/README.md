## Estratégia utilizada

Cada resposta é armazenada em uma variável com nome significativo. As mensagens finais usam f-strings para combinar rótulos fixos e valores informados pelo usuário.

Os valores permanecem como strings. Conversão e cálculo não fazem parte deste capítulo.
