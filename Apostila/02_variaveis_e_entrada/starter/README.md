# Arquivos iniciais — Capítulo 2

Esta pasta permite iniciar o encontro sem depender dos arquivos do Capítulo 1.

| Arquivo | Finalidade |
|---|---|
| `verificar_capitulo.py` | Confirmar que o ambiente executa Python. |
| `ficha_base.py` | Ponto de partida para a prática acompanhada. |
| `nome_incorreto.py` | Investigar um `NameError` intencional. |

## Como começar

1. Copie esta pasta para um local em que você possa editar os arquivos.
2. Abra a pasta copiada no VS Code.
3. Execute `verificar_capitulo.py`.
4. Compare a saída com o capítulo.
5. Não corrija `nome_incorreto.py` antes da oficina de depuração.
