## Estratégia utilizada

Textos descritivos permanecem como strings. Quantidades são convertidas para `int` e preços para `float`. Os cálculos acontecem somente depois das conversões.

Os exemplos supõem entradas válidas. Condicionais e tratamento de exceções pertencem a capítulos posteriores.
