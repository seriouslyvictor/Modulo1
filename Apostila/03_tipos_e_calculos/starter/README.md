# Arquivos iniciais — Capítulo 3

Esta pasta permite iniciar o encontro sem depender dos arquivos anteriores.

| Arquivo | Finalidade |
|---|---|
| `verificar_capitulo.py` | Confirmar que o ambiente executa Python. |
| `calculadora_base.py` | Ponto de partida para a prática acompanhada. |
| `soma_textual.py` | Investigar um erro de lógica causado por strings. |

## Como começar

1. Copie esta pasta para um local em que você possa editar os arquivos.
2. Abra a pasta copiada no VS Code.
3. Execute `verificar_capitulo.py`.
4. Não altere `soma_textual.py` antes da oficina de depuração.
