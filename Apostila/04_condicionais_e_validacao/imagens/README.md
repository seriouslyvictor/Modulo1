# Imagens — Capítulo 4

Este capítulo não exige capturas de tela. O fluxo das decisões é representado por código, tabelas de condições e sequências textuais.

Um diagrama só deverá ser adicionado se a validação em sala mostrar dificuldade persistente para acompanhar a ordem de `if`, `elif` e `else`. Ele deverá complementar, e não substituir, a explicação textual.
